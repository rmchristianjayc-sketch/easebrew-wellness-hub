# UAT Checklist — Customer

**Audience:** Filipino seniors 50+ (real users)
**Time commitment:** 15–20 minutes across 5 days
**Language:** Tagalog
**Send via:** Messenger

*Coach note: pin this in the UAT group chat after each tester gets their code.*

---

## Araw 1 — Setup + Home (5 min)

- [ ] Buksan ang link sa cellphone browser (Chrome o Safari)
- [ ] Ilagay ang inyong personal test code
- [ ] I-tap ang "Buksan ang Hub Ko"
- [ ] Nakita ba niyo ang onboarding welcome? Sagutin o i-Laktawan
- [ ] I-install ang app sa home screen (may prompt — i-tap "Yes! I-install")
- [ ] Sa **Home tab**, i-tap ang emoji na tumutukoy sa pakiramdam niyo (☺ 😐 😴 😷)
- [ ] I-tap ang **Umagang EaseBrew** at/o **Gabing EaseBrew** kung na-inom niyo na
- [ ] **REPORT:** May button ba na hindi umaandar o hindi malinaw?

## Araw 2 — Blood Pressure + Tracker (3 min)

- [ ] Buksan ang **Blood Pressure Log** (mula Home → Libreng Health Tools)
- [ ] Mag-log ng isang BP reading (kahit gawa-gawa lang) — Petsa: ngayon, Systolic: 120, Diastolic: 80
- [ ] I-save
- [ ] Bumalik sa Home
- [ ] I-tap ang **Tracker** (kung available sa inyong tier)
- [ ] Tignan ang bagong layout — dapat may **isang malaking button** para sa EaseBrew AM/PM
- [ ] I-tap ang Umaga button
- [ ] I-tap ang **"I-save ang Record"** (sticky sa ibaba)
- [ ] **REPORT:** Kung nawala ang data, kung mali ang layout, o kung may button na naka-hide.

## Araw 3 — Meal Plan + Recipes (3 min)

- [ ] Buksan ang **Meal Plan** (kung available)
- [ ] **NGAYONG ARAW** hero — dapat kita niyo agad ang pagkain para sa araw na ito
  - Agahan, Tanghalian, Merienda, Hapunan
  - EaseBrew reminder (Umaga at Gabi)
- [ ] I-tap ang **"Tapos na ngayong araw!"** button
- [ ] I-tap ang **"Tingnan Lahat ng Meal Plan"** para makita ang buong 50-day list
- [ ] Bumalik sa Home
- [ ] Buksan ang **Recipes** (kung available)
- [ ] I-favorite ang isang recipe (i-tap ang puso)
- [ ] Isara at buksan ulit ang app — nandito pa ba ang paborito niyo?
- [ ] **REPORT:** Kung mahirap basahin ang meal text o kung nawala ang paborito.

## Araw 4 — Exercise + Gamot Log (3 min)

- [ ] Buksan ang **Exercise** (kung available)
- [ ] Basahin ang **"Basahin muna: Safety Guide"** — i-tap "Naintindihan ko"
- [ ] Pumili ng Phase 1 → Day 1
- [ ] I-tap ang isang exercise para makita ang instructions + video
- [ ] Kung may video: umandar ba? Nag-loop ba? May lumalabas na "related videos" sa dulo?
- [ ] I-tap ang **checkbox** para markahan na tapos ang isang exercise
- [ ] Subukang i-tap ang exercise TEXT (hindi ang checkbox) — dapat hindi ito nagmarka na tapos
- [ ] Buksan ang **Gamot Log**
- [ ] Magdagdag ng gamot: Losartan, 1 tablet, umaga
- [ ] I-save at bumalik
- [ ] Buksan ulit ang **Gamot Log** — nandito pa ba?
- [ ] **REPORT:** Kung nag-marka na tapos kahit hindi na-tap ang checkbox, o kung nawala ang data.

## Araw 5 — Coach tab + Family Share (2 min)

- [ ] I-tap ang **Coach** tab (bottom nav)
- [ ] Tignan ang coach cards — kompleto ba ang info?
- [ ] I-tap ang **Call** button ng isang coach — dapat may lumabas na dialer (wag na po tumawag)
- [ ] I-tap ang **Facebook** button — dapat may lumabas na FB page
- [ ] Sa parehong Coach tab, hanapin ang **"Ipakita sa Pamilya"** card
- [ ] I-tap ang **"I-share sa Pamilya"** — dapat lumabas ang Messenger o Share sheet ninyo
- [ ] I-share sa sariling account niyo para ma-test
- [ ] Buksan ulit ang app — dapat may kulay-luntiang ✓ **"Naibahagi na sa Pamilya"** at may "Valid hanggang [petsa]"
- [ ] **REPORT:** Kung hindi lumabas ang share sheet, o kung hindi naaalala ng app na na-share niyo na.

---

## Katapusan — pangkalahatang feedback

Bigyan po ng 1-liner:

1. Anong bahagi ang **pinakamadali** gamitin?
2. Anong bahagi ang **pinakamahirap** o hindi maintindihan?
3. May button ba na feeling niyo nawawala o hindi makita?
4. Kaya niyo ba i-recommend ito sa kaibigan? **Oo / Hindi / Depende**
