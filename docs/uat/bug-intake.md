# Bug Intake Template

**Pin ito sa Messenger group chat na "EaseBrew UAT — Bug Reports"**

---

*(Copy-paste sa Messenger para sa mga tester)*

## Paano mag-report ng problema

Kapag may nakita kayong hindi tama, i-message sa group chat na ito. Sagutan ang template sa ibaba. Kahit 1–2 lang ang sagot niyo, OK po.

```
📱 Phone: (hal. iPhone 12 / Samsung Galaxy A54 / Xiaomi)
📍 Saan: (hal. Coach tab / BP Log / Recipes)
❌ Ano ang problema: (1 sentence lang)
🖼 Screenshot: (attach kung kaya)
```

## Halimbawa

```
📱 Phone: Xiaomi Mi 11i
📍 Saan: Coach tab sa verify page
❌ Ano ang problema: Yung blue Facebook button, sumusobra sa card
🖼 [screenshot attached]
```

## Wag pong mag-atubili

Kahit maliit na bagay — hal.:
- "Yung text medyo maliit para sa akin"
- "Hindi ko alam kung anong ibig sabihin ng button na ito"
- "Nag-crash ang app pag pinindot ko ito"

**Lahat po ay tumutulong.**

---

## Para sa R&M (coordinator): triage log

Tally ang bawat report sa table na ito habang dumadating:

| # | Petsa | Tester | Phone | Page | Problema | Severity | Fixed? |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | BLOCKER / HIGH / NICE | |

**Severity guide:**
- **BLOCKER** — can't verify code, data lost, app crashes, wrong tier gate
- **HIGH** — visible layout issue, wrong Tagalog text, confusing flow
- **NICE-TO-HAVE** — cosmetic, "would be nice if"

Kapag natapos ang 5 araw, i-forward sa akin ang triage log at ang mga screenshots.
